# 业务调研一页纸 · 货代客服的一天

> 项目：跨境物流智能客服工作台（Logistics Copilot） · 调研方式：业务访谈（模拟）+ 工单抽样统计（模拟数据） · 日期：2026-08-29

---

## 一、场景：货代客服的一天

货代/跨境物流公司的客服团队每天通过**邮箱、微信、电话**三个渠道接收客户求助：

```
客户求助（邮件/微信/电话）
   │  ①人肉读消息，判断是什么问题
   ▼
查系统（船期/库存/账单/清关状态）──→  ②抄提单号/柜号进 TMS
   │                                    │
   ▼                                    ▼
③回复客户（流程问题要问老员工）      ④催上游（船司/仓库/报关行）
```

一位客服一天处理 60~80 条消息，其中大量时间耗在**重复查询、抄写录入、翻找流程**上。

## 二、痛点（按访谈与抽样统计）

| # | 痛点 | 量化（模拟数据估算） |
|---|------|---------------------|
| 1 | **重复查询多**：约 45% 的消息是船期/费用/流程类重复咨询（滞箱费怎么算、免堆期几天、清关要什么资料），每条人工回复约 5 分钟 | 45% × 5 分钟 ≈ 每人每天 2.5~3 小时耗在"复读机"式回复 |
| 2 | **抄写录入慢且易错**：消息里的提单号、柜号、港口、费用争议点要人工读出并抄进系统，每单约 3 分钟，抄错单号还会引发二次返工 | 每天约 50 单 × 3 分钟 ≈ 2.5 小时；抄错率约 3%~5% |
| 3 | **流程知识在老员工脑子里**：清关资料、免箱期规则、改单流程散落在老员工经验里，新人遇到流程问题只能逐个问，上手周期长 | 新人独立上岗约需 1~2 个月，高频打断老员工 |

## 三、痛点 → 需求抽象（业务需求 / 系统需求 / AI 需求 / 自动化需求）

这是本项目的核心动作：把"业务痛点"逐条翻译成可建设的系统与 AI 能力。

| 业务痛点 | 系统需求 | AI 需求 | 自动化需求（远期） |
|---|---|---|---|
| 重复查询多、回复慢 | FAQ 知识库统一管理（Obsidian 维护，入库可检索） | **RAG 知识库问答**：检索 FAQ 片段 → 拼提示词 → 生成带来源的回答 | 接入企业微信/邮箱，自动回复高频问题 |
| 抄写录入慢、易错 | 工单表 + 结构化字段（提单号/柜号/起运港/目的港…） | **LLM 信息提取**：从非结构化消息提取 8 类字段 + 分类 + 紧急度 | RPA 把提取结果回写 TMS/CRM |
| 新人不会答、回复质量参差 | 工单留痕 + 建议回复审核发送 | **建议回复生成**：按工单类型产出专业话术，人审后发送 | 一键贴回邮箱/微信对话框 |
| 主管看不清运营状况 | 看板数据底座（SQL 聚合指标） | （P1）把统计数据喂给 LLM 生成数字化改善建议 | 定时推送日报到群 |

## 四、解决方案（本系统）

```
非结构化求助消息(CSV/粘贴)
   ──→ AI 管道：字段提取(8字段) + 分类(仓储/运输/关务/账单) + 紧急度 + 意图 + 建议回复
   ──→ 结构化工单入库（SQLite/PostgreSQL 可切换）
工单台（列表/详情/一键复制建议回复）  ←  FastAPI  →  知识库问答（RAG + 来源标注）
                                        →  运营看板（KPI 卡片 + 趋势/分布/意图/超时，SQL 聚合）
```

- **降级设计**：无 API Key / 断网 / LLM 报错时自动切纯规则（正则提单号柜号 + 关键词分类），全流程不断。
- **存储分层**：工单与问答日志 → 数据库（结构化、可聚合）；FAQ 与调研文档 → `kb/` Obsidian Markdown 库（业务可直接维护，脚本幂等同步入库）。

## 五、价值预估（用本项目模拟数据计算）

- **AI 自动处理率 ≈ 45%~55%**：分类/提取/建议回复全自动完成，覆盖约一半的重复咨询；
- **录入时间节省 ≈ 80%**：提单号/柜号/港口 8 字段自动提取，3 分钟/单 → 约 20 秒/单（人工仅需校对）；
- **新人答疑不再依赖老师傅**：知识库问答带来源标注，答不上自动转人工，FAQ 维护交给业务侧；
- **超时可视化**：看板自动暴露超 4 小时未响应工单，响应 SLA 可管可控。

> ⚠️ 诚信声明：以上数字均由**模拟数据**计算得出（管道真实、数据为造），用于验证方案可行性与价值量级；真实落地第一步是拿历史真实工单离线评测一个月。
