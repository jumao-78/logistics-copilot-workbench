# 海运附加费说明（THC/文件费/BAF等）

## 常见附加费一览

| 简称 | 全称 | 说明 | 参考标准 |
|---|---|---|---|
| THC | Terminal Handling Charge | 码头操作费 | 20GP RMB 480 / 40HQ RMB 750 左右 |
| DOC | Documentation Fee | 文件费 | RMB 300/单（每份提单收一次） |
| BAF | Bunker Adjustment Factor | 燃油附加费 | 随油价浮动，船司按月公布 |
| CIC | Container Imbalance Charge | 集装箱不平衡费 | 旺季常见，USD 50~150/柜 |
| SEAL | 封条费 | 铅封 | RMB 20~35/个 |
| EIR | 设备交接单费 | 提柜单 | RMB 50/柜 |

## 计费注意事项

1. 文件费按提单份数收：一票货分出两份提单，应按两份收；同一份提单不重复收取；
2. THC 分起运港（OTH）与目的港（DTH），报价时需确认含不含；
3. 汇率：船司账单多用美元计价，我司账单按开票日汇率折算，备注栏会注明汇率；
4. 报价与账单差异：以订舱确认时的报价单为准，账单多收部分核实后退还或冲抵。

## 常见问题

1. 账单比对报价多了 THC：确认是起运港还是目的港 THC，漏看一项是常见原因；
2. 同一票货两个提单号收了两次文件费：属于正常（每份提单一次），若同一提单号重复收取则核实退款；
3. 月结：货量稳定客户可申请 30 天账期月结，签对账协议后每月 5 日出上月账单。

## 温馨提示

对账时请提供提单号+费用金额，客服可调出原始报价单与船司账单逐项核对。
